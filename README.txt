v5.3 使用方式
1. 先保留原始 v5.2 JSON 備份。
2. 將 index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png 上傳 GitHub Pages 同一層，覆蓋舊版。
3. 開啟新版，先從備份／還原匯入「財務回報簿_11月15日對帳備份.json」。匯入會覆蓋當前瀏覽器資料。
4. 11/15 前29筆紀錄保留但不重扣；之後新增紀錄會更新餘額。
5. 發票匯入請先比對既有紀錄；已發生消費選歷史模式，勿重扣。
6. 信貸繳款只扣現金，信貸本金需依銀行資料手動校正。
7. 私人財務總覽預設隱藏，這不是密碼保護。
